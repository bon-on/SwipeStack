# 기능 명세: SwipeStack 시각 개편, 착지 손맛, 재플레이 동기

## Problem
SwipeStack은 단색 둥근 사각형과 어두운 그라데이션만 있어 시제품처럼 보인다. 착지 순간의 연출(완벽 착지, 잘려 나가는
조각, 무너짐)이 거의 없고 배경음악도 없다. 최고 기록 외에는 판이 끝나도 남는 것이 없어 다시 플레이할 이유(목표,
성장, 꾸미기)가 없다. 포털(CrazyGames 등) 품질 기준을 통과할 수 있는 완성도 있는 캐주얼 게임처럼 보여야 한다.

## Scope
1. 시각 개편: 하늘로 쌓는 타워
   - 블록은 외부 에셋 없이 `CustomPainter`로 그린 건물 층/상자다(창문, 처마, 기둥, 테마별 장식). 맨 아래 기초 블록은
     출입문이 있는 로비다. 폭이 아주 좁아져도 창문 수가 줄어들 뿐 그림이 깨지지 않는다.
   - 카메라는 타워 높이를 부드럽게 따라 올라간다. 하늘은 높이에 따라 낮(구름, 해) -> 노을 -> 황혼 -> 우주(별, 행성)로
     이어지고, 구름/먼 스카이라인은 시차(parallax)로 움직인다. 지면에는 테마별 스카이라인이 있다.
   - 최고 기록 높이에 "BEST" 표시선을, 10층마다 높이 눈금을 그린다.
   - 테마 4종(블록 + 스카이라인): Downtown(Lv1, 기본), Harbor(Lv3, 나무 상자와 둥근 창, 항구 크레인),
     Candy(Lv6, 크림 장식 파스텔 층, 사탕 언덕), Neon(Lv10, 네온 테두리 유리 층, 밤의 도시). 꾸미기 전용이며 규칙에
     영향을 주지 않는다.
   - 넓은 화면(1280x720, 1366x768 iframe)은 가운데 플레이 필드(폭 최대 520)와 좌우 패널(높이/최고/속도, 레벨과 XP,
     미션, 조작 안내, 테마)로 배치한다. 좁은 화면(390x844)은 헤더, 통계, 플레이 필드, 미션 줄을 위아래로 쌓는다.
     어느 크기에서도 오버플로가 없어야 한다.
   - 패널, 버튼, 타이포그래피(제목/수치/라벨 위계)를 새 룩으로 통일하고 튜토리얼 카드도 같은 스타일로 바꾼다.
2. 착지 손맛(연출은 규칙을 기다리게 하지 않는다)
   - 완벽 착지: 블록 섬광과 링, "Perfect!" 팝업, 2연속 이상이면 "Perfect x3" 같은 연속 배너, 전용 효과음.
     3연속 이상(폭이 다시 자라는 구간)은 더 높은 효과음.
   - 불완전 착지: 잘려 나간 조각이 회전하며 떨어지고, 착지 먼지와 짧은 눌림(squash), 위층의 작은 흔들림(wobble).
   - 착지마다 "+1" 팝업.
   - 위험 표시: 블록 폭이 좁아지면(기본 폭의 25% 미만) 플레이 필드 가장자리에 붉은 맥동, 정렬이 실패 범위면 착지
     가이드가 붉게 바뀐다(기존).
   - 게임 오버: 떨어지는 블록이 굴러 떨어지고 위쪽 몇 층이 무너지며 화면이 흔들린다.
   - 모든 연출은 화면의 단일 Ticker 시계로 돌아가며, 규칙 처리(착지, 실패, 재시작)는 즉시 적용되고 연출은 뒤따른다.
3. 판 안의 목표: 미션
   - 판마다 미션 3개(서로 다른 종류): N층 쌓기, 완벽 착지 N회, 완벽 N연속, 폭 절반 이상 유지한 채 N층.
     목표치는 플레이어 레벨에 따라 조금씩 커진다. 달성 즉시 체크 표시, 효과음, 배너, XP 보상이 붙는다.
4. 판 사이의 동기: 결과 화면, 레벨, 테마
   - 결과 화면: 제목 "Tower slipped", 높이(층), 최고 기록과 "New best!", 완벽 착지 수와 최장 연속, 미션 결과,
     획득 XP, 레벨 진행 바, 새로 열린 테마, "Play again"(Enter/Space/R/Esc)과 "Themes" 버튼.
   - 플레이어 레벨: XP = 층수 x 2 + 완벽 착지 x 3 + 미션 XP + 참가 보너스 10(3층 이상). 레벨 L에서 다음 레벨까지
     60 + 20 x (L - 1) XP. 판 도중 재시작(R, 버튼)도 그 판을 끝난 것으로 반영한다(0층 판은 제외).
   - 테마 선택 오버레이: 열린 테마만 고를 수 있고 잠긴 테마는 요구 레벨을 보여준다. Esc/Enter로 닫는다.
   - 최고 기록은 기존 `best_stack` 키(`BestStackStore`)를 그대로 쓴다(데이터 손실 없음). 저장값을 읽기 전에는
     최고 기록을 쓰지 않고, 읽은 뒤 더 큰 값으로 합친다.
   - XP, 선택 테마, 누적 통계는 새 키 `tower_progress_v1`(JSON)에 저장한다. 손상되거나 없는 값은 기본값으로
     대체되고 플레이를 막지 않는다. 저장값을 읽기 전에 끝난 판은 읽은 뒤 합쳐서 저장한다.
5. 소리
   - 경쾌하고 가벼운 배경음악 루프(코드 합성, 16000 Hz 모노 16비트, 1 MB 이하)를 `tool/generate_sounds.py`
     (표준 라이브러리만, 결정적 출력)로 만든다. 기존 drop/stack_success/fail은 다시 만들지 않는다.
   - 새 효과음: perfect, streak, mission, level_up.
   - 웹에서는 첫 사용자 입력 이후 시작, 탭이 숨겨지면 멈췄다가 돌아오면 재생, 전면 광고 동안 멈추고 닫힘 콜백 후
     재개한다. 하나의 소리 토글이 효과음과 음악을 모두 끈다. iOS/Android 네이티브 채널에 `play`, `startLoop`,
     `stopLoop`을 추가한다(기존 메서드 이름 유지).

## Acceptance Criteria
- 모든 테마 x 블록(기초, 일반, 움직이는 블록, 좁은 블록)이 일러스트로 그려지고 예외 없이 그려진다.
- 하늘이 카메라 높이에 따라 낮/노을/우주로 바뀌고 구름은 시차로 움직인다.
- 완벽 착지 시 섬광, 팝업, 연속 배너가 보이고 불완전 착지 시 잘린 조각이 떨어진다. 게임 오버 시 무너짐 연출이 있다.
  연출 중에도 입력(드롭, 넛지, 재시작)은 즉시 처리된다.
- 판마다 미션 3개가 보이고 조건 충족 시 완료 표시와 XP 보상이 적용된다.
- 결과 화면에 높이, 최고 기록, 신기록 여부, 완벽 착지, 미션, 획득 XP, 레벨 진행, 해금 테마가 표시되고 다시 하기로
  새 판이 시작된다.
- 최고 기록(`best_stack`), XP, 선택 테마가 다시 열어도 유지된다. 손상된 `tower_progress_v1`은 기본값으로 대체된다.
- 테마는 요구 레벨 도달 시 열리고 선택한 테마의 블록과 스카이라인이 그려진다. 잠긴 테마는 고를 수 없다.
- 배경음악은 음소거, 탭 숨김, 광고 동안 멈춘다.
- 키보드 조작(Space/Enter/ArrowDown 드롭, Left/Right/A/D 넛지, R 재시작), 튜토리얼, 전면 광고 주기(3판마다)는
  기존대로 동작한다. 오버레이(튜토리얼, 결과, 테마)가 열려 있으면 플레이 입력이 막히고 Esc/Enter로 닫거나 다시 시작한다.
- 1280x720, 1366x768, 390x844에서 오버플로 없이 표시된다.

## Constraints
- 새 패키지 의존성을 추가하지 않는다. 그림은 코드로, 소리는 생성기로 만든다. lib/ 문자열은 영어 ASCII다.
- 겹침 판정, 속도 단계, 완벽 착지/폭 회복 규칙은 바꾸지 않는다(`adr-swipe-stack-deterministic-stacking`).
  컨트롤러는 연출용 착지 정보(잘린 조각, 완벽 여부)와 판 통계(완벽 착지 수, 최장 연속, 판 시작 시 최고 기록)만 추가한다.
- GitHub Pages 웹 빌드는 광고 없이 동작한다(`adr-swipe-stack-pwa-pages`). 웹 자산은 모두 번들이며 외부 요청이 없다.
- 이 저장소에는 포털 빌드 스크립트를 추가하지 않는다.
